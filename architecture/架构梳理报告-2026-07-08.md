## 一、项目概览

VisionBata 是一个基于 **PyQt6** 的桌面端视觉检测平台，集成：

- **多摄像头采集**（PyAV / DirectShow）
- **YOLOv8 推理**（ultralytics 的 PyTorch 路径 + ONNX Runtime / DirectML 加速路径）
- **卡尔曼滤波跟踪**（纯 NumPy 实现的 UKF / MCUKF / Manifold-UKF，及线性卡尔曼用于矩形）
- **自定义绘制 GUI**（Fusion 暗色主题，1~4 路摄像头网格）

核心目标：实时采集视频 → 推理得到检测/姿态/手势 → 跟踪平滑 → 叠加绘制显示，并支持录像。

## 四、推理管线（`ai/inference.py`）

`InferWorker(QThread)`（约第 195 行）是唯一的共享推理线程，服务全部摄像头槽位。

**关键信号**
- `detection_ready = pyqtSignal(int, list)` → `(slot_id, detections)`
- `model_ready = pyqtSignal(str, bool, str)`

**模型加载**
- `_detect_device()`：CUDA 可用则用 `cuda`，否则 `cpu`。
- `_initialize_backend()`：按 `backend` 选择 `pytorch / onnx / directml / cpu`；DirectML 失败则整体禁用 AI。
- 检测模型 `yolov8n.pt`，姿态模型 `yolov8n-pose.pt`；`_resolve_artifact_path()` 先查 `models/` 再查根目录（修复过因路径错误触发自动下载的历史 bug）。
- ONNX 后端经 `OnnxYoloBackend`（DirectML 加速）。

**逐帧推理 `_run_inference()`**
- ONNX 路径：`model.predict(frame, conf)` → 过滤。
- PyTorch 路径：`model(frame, conf, imgsz=640, device)`，读取归一化 `box.xyxyn`。
- 超分辨率：开启骨架时，对低置信小人框用 ESPCN（`cv2.dnn_superres`）上采样后重跑。
- 检测字典：`{x1,y1,x2,y2,confidence,label,keypoints}`，关键点取自 `r.keypoints.xyn`。

**ROI 重检测** `_redetect_person_in_roi()`：person 轨迹丢失时，按预测框裁切（+15% pad）低置信重跑 YOLO 并映射回归一化坐标；受启动守卫与最大重试次数限制。

**去重** `final_dedupe()`：按标签 IoU 合并（person 0.55 / rectangle 0.30 / hand_gesture 0.35）。

**帧调度**：`submit_frame()` 按 `_target_ai_interval` 节流；仅 `frame_id % _infer_stride == 0` 执行完整推理，其余帧用 `predict_step()` 卡尔曼预测填充。

## 五、跟踪（`ai/tracker.py` + `ai/rectangle_detector.py`）

**人体跟踪 `DetectionTracker`**
- IoU 贪心匹配 + 中心点距离兜底；EMA 平滑框与 17 关键点；`max_misses` 默认 2 删除轨迹。

**滤波器实现（纯 NumPy，无 filterpy/scipy）**
- `_DetectionUKF`（8 维状态 `[cx,cy,w,h,vx,vy,vw,vh]`，无迹变换，Cholesky 带恢复）。
- `_DetectionMCUKF`：最大相关熵加权 + 不动点迭代 + Joseph 形式协方差，抗离群值。
- `_DetectionManifoldUKF`：特征分解 `P^½` + SPD 投影（特征值裁剪 `[1e-8, P_MAX]`），长跳帧数值稳定。

**AUTO 自适应切换 `_FilterAdaptor`**
- 监控 NIS、缺失率、P 条件数（`np.linalg.cond`）、Cholesky 失败次数。
- 决策：`cond>500` 或 cholesky 失败 >2 → manifold_ukf；平均 NIS>5.0 或 缺失 >40% → mcukf；否则 ukf。
- 迟滞：连续 2 次评估一致才切换；`_Track.swap_filter()` 热切换保留 `x,P,Q,R`。

**矩形跟踪 `RectangleTracker`（线性卡尔曼）**
- `RectangleDetector.detect()`：灰度 → CLAHE → Canny → 形态学 → 轮廓 → 四边形近似 → 几何/角度/填充/平行/边缘评分；预设 `low/medium/high`。
- 匹配用 IoU + 中心点 + 尺寸评分；输出 4 点 polygon 供绘制。

## 六、摄像头层（`camera/`）

- **`SingleCameraWorker(QThread)`**：每槽一路，PyAV `av.open(f"video={device_name}", format="dshow", ...)` 解码，`frame_ready(slot_id, rgb_ndarray)`。
- **`CameraCapture`**：按 `slot_id` 管理 worker，`QMutex` 保护启停。
- **`scan_cameras()`**：多后端枚举优先级 —— Qt6 `QMediaDevices` → PyAV dshow 探测（亮度校验）→ OpenCV `CAP_DSHOW` 兜底。
- **`VideoRecorder`**：每槽 `_RecorderThread`（守护线程），PyAV 写 H.264 `yuv420p` MP4；`ThreadPoolExecutor(max_workers=4)`；默认输出 `recordings/`，命名 `slot_{id}_{timestamp}.mp4`。

## 七、GUI 层（`gui/`）

- **`MainWindow`**：`_MAX_SLOTS = 4`；顶部栏 + 控制侧栏 + 4 格网格。侧栏含概览/设备/运行/存储卡片；功能面板含人体/骨架/手势模式/矩形等开关与参数。双击单元格可放大。
- **信号/槽连接**（`_on_camera_selected`）：
  ```
  worker.frame_ready → cell.update_frame              # 画面显示
  worker.frame_ready → infer.submit_frame(DirectConnection)  # 送推理（AI 开）
  infer.detection_ready → cell.update_detections      # 检测结果→显示
  worker.frame_ready → _on_frame_for_recording        # 送录像（录像开）
  ```
  `_on_ai_toggled` 实时连接/断开推理路径；启动守卫 `infer.prepare_startup_guard()`。
- **`CameraCell`**：`update_frame()` 将 RGB ndarray 转 `QImage` 并按 ~30fps 节流重绘；`update_detections()` 缓存 bbox（TTL 2.0s，最大帧龄 0.28s 防过期叠加）；`paintEvent` 绘制画面、边框、骨架、矩形、FPS 等信息。
- **`SettingsDialog`**：暴露置信阈值、推理步长、平滑系数、隐藏延迟、重检测次数、ROI pad、**滤波器类型**（ukf/mcukf/manifold_ukf/auto）、MCUKF 核带宽、去噪方法与强度、模型切换、矩形参数等。

## 十、端到端数据流与线程模型

```
摄像头 (SingleCameraWorker, QThread)
   │  av.open(dshow) → rgb ndarray
   ├─ frame_ready(slot_id, frame)
   │    ├─→ CameraCell.update_frame            → paintEvent 显示（节流30fps）
   │    ├─→ InferWorker.submit_frame (DirectConnection, AI开) → _buffers[slot]
   │    └─→ VideoRecorder.push_frame (录像开)
   ▼
InferWorker (QThread, 全部槽位共享)
   │  run() 循环：快照所有槽位缓冲 → 逐槽位：
   │    if frame_id % stride == 0:
   │       可选去噪 → _run_inference(YOLO/ONNX)
   │       → DetectionTracker.update（UKF/MCUKF/Manifold + ROI 重检测）
   │       + 矩形检测 + 手部手势检测
   │       → 显示过滤 + final_dedupe
   │    else: detections = tracker.predict_step() + 保留非人体
   │  emit detection_ready(slot_id, detections)
   ▼
CameraCell.update_detections(slot_id, detections)
   │  缓存 + TTL + 叠加缓存重建 → paintEvent 绘制
```

**线程模型**
- 1 个 GUI 线程（`QApplication`）
- N 个摄像头线程（`SingleCameraWorker`，最多 4）
- 1 个推理线程（`InferWorker`）跨所有槽位共享，每槽位缓冲在 `threading.Lock` 下
- 录像在 `ThreadPoolExecutor` 守护线程
- `frame_ready → submit_frame` 用 `DirectConnection` 在摄像头线程同步提交；`detection_ready → update_detections` 排队跨线程；叠加绘制仅 GUI 线程

## 十一、关键技术约定

- **硬编码路径 / venv**：`start.bat` 硬编码 `F:\VisionBata`；模型解析 `_resolve_artifact_path()` 先 `models/` 后根目录。
- **全程归一化坐标**：检测统一 `[0,1]`，绘制时映射到像素并支持水平翻转（`1.0 - x`）；缩放使缓存失效防漂移。
- **ROI 重检测**：仅 `person` 标签，启动守卫 + 最大重试限制。
- **图像去噪**：`_denoise_frame` 支持 `bilateral` / `nl_means`（>720p 自动 2× 降采样），仅作用于推理帧。
- **AUTO 自适应滤波**：NIS / 条件数 / Cholesky 失败驱动，迟滞 2 次（见 `docs/auto-filter-adaptive-plan.md`）。
- **超分辨率**：ESPCN 提升小人检测，缺失 `.pb` 时优雅禁用。
- **启动守卫**：3 秒窗口抑制早期帧 ROI 重检测。
- **调试遥测**：`_debug_report()` 向 `http://127.0.0.1:7777/event` POST（受 `try/except` 保护，不破坏主流程）。
- **手势模式**：`body` / `hand` / `all` / `off`，由 `normalize_gesture_mode` 归一化。
- **录像命名**：`slot_{slot_id}_{YYYYMMDD_HHMMSS}.mp4`。
- **UI**：暗色"冷蓝灰" Fusion 主题；大量 `QPropertyAnimation`；`WheelFocus*` 防滚轮抢焦点。

## 十二、检查结论与建议（仅观察，未改动）

**架构亮点**
- 推理线程与摄像头线程解耦，单推理线程共享多路，资源利用合理。
- 跟踪滤波器纯 NumPy 实现、可热切换，工程可维护性强。
- 信号/槽 + 直接连接混合设计，兼顾实时性与线程安全。

**潜在可优化点（供参考，未修改）**
1. `start.bat` 及部分路径硬编码 `F:\VisionBata`，迁移/部署需注意。
2. `models/yolo26s.pt` 默认路径逻辑未使用，可清理或显式接入。
3. 调试遥测 `_debug_report()` 默认指向 `127.0.0.1:7777`，生产环境建议默认关闭。
4. ONNX 与 PyTorch 双后端并存，建议明确默认路径并统一配置入口。
5. 配置文件分散在 QSettings 注册表，跨机器迁移不便，可考虑导出/导入 JSON。
